# Android setup — SHADOW UCHIHA

1. Download `shadow-uchiha-project.zip` and extract it using your phone's Files app.
2. Open your GitHub repository in Chrome.
3. Tap **Add file → Upload files**.
4. Upload `index.html`, the `supabase` folder, the three policy pages, `_headers`, `_redirects`, and `README.md`. Keep `index.html` at the repository root.
5. Scroll down, add a commit message such as `Add SHADOW UCHIHA starter`, then tap **Commit changes**.

If GitHub mobile cannot upload folders, open Chrome's menu and try **Desktop site**, or upload files in batches.

## Preview
- GitHub Pages: repository **Settings → Pages**, choose deployment from the main branch and root folder, then save.
- Approved final host: Cloudflare Pages connected to this GitHub repository. For plain HTML, no build command is needed and the output directory is the repository root.

## Important before launch
The current file is only a visual prototype. Secure login, admin approval, real catalogue data, and video publishing still need configuration and testing. Replace placeholder contact details. Do not put secret keys in frontend files. Do not publish copyrighted anime unless you have permission. Do not activate billing.
